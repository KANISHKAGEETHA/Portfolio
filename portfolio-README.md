## Built with care

- **Works on every screen:** phones, tablets and desktops, with a hamburger menu on small screens.
- **Light and dark themes:** follows your device setting, and the toggle remembers your choice.
- **Accessible:** keyboard navigation, visible focus outlines and reduced-motion support.
- **Fast:** one HTML file, no frameworks and no build step.
- **Typing role line, live navigation highlight and expandable project cards:** small touches that make it feel alive.

## How the contact form works

```
 Visitor ──► Portfolio form ──► Node.js backend ──► My Gmail inbox
                                      │
                                      └──► Auto-reply to the visitor
```

The backend lives in its own repo: **[portfolio-backend](https://github.com/KANISHKAGEETHA/portfolio-backend)**. If the server is asleep or unreachable, the form falls back to opening the visitor's email app, so a message can still reach me.

## Run it on your machine

```bash
git clone https://github.com/KANISHKAGEETHA/portfolio.git
cd portfolio
# open index.html in your browser. That's it.
```

To connect your own backend, set `BACKEND_URL` near the bottom of `index.html`.
